# Настройка автоматического резервного копирования HOSTVM Manager

Раздел включает два руководства:

* **Настройка автоматического резервного копирования управляющей машины развернутой в режим Standalone** – для случаев, когда HOSTVM Manager установлен на отдельном выделенном сервере (физическом или виртуальном).
* **Настройка автоматического резервного копирования управляющей машины развернутой в режим Self-Hosted** – для конфигураций, где HOSTVM Manager работает внутри виртуальной машины, размещенной на хостах того же кластера, которым он управляет, что требует специального подхода к сохранению и восстановлению данных.

Материалы раздела помогут администраторам настроить регулярное создание резервных копий базы данных и конфигурационных файлов менеджера, обеспечивая отказоустойчивость системы управления виртуализацией и возможность экстренного восстановления в случае критических сбоев.

{% hint style="warning" %}
Локальный каталог на управляющей машине не должен быть единственным местом хранения резервных копий. После успешного создания копии рекомендуется переносить ее на отдельное хранилище, например NFS, SFTP-сервер или резервное хранилище предприятия.
{% endhint %}
