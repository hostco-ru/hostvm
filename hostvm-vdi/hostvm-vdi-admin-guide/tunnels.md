# Туннели

> Описываемый функционал доступен начиная с версии брокера 4.0

Раздел "Подключение / Туннели" панели управления позволяет добавлять туннелеры HOSTVM VDI, ранее созданные и зарегистрированные на брокере, для последующего использования в настройках транспортов.

## Добавление туннелера <a href="#create-tunnel" id="create-tunnel"></a>

Для добавления туннелера  перейдите в раздел "Подключение" > "Туннели", нажмите "Новый".

В открывшемся окне задайте его параметры:

* **Имя (Name)** - имя создаваемого элемента для отображения в системе.
* **Имя (Hostname)** - fqdn или ip-адрес туннелера.
* **Порт (Port)** - порт туннелера, по которому он доступен пользователям. По умолчанию, туннелер использует один из двух портов, в зависимости от типа транспорта:
    - `10443` для HTML5 транспортов;
    - `443` для остальных туннелированных транспортов (RDP, RDS, X2Go и т.д.).

**Примечание:**
- при подключениях из-за пределов локальной сети необходимо указывать внешний IP-адрес / FQDN и порт, по которым туннелер будет доступен пользователям;
- при использовании нескольких туннелеров за балансировщиком нагрузки в конфигурации высокой доступности необходимо указывать адрес / имя балансировщика, и порт, в соответствии с настроенными правилами балансировки.

Нажмите "Сохранить". Повторите процедуру для добавления всех требуемых туннелеров.

После завершения настройки туннелера, вы можете указать его в настройках туннельных транспортов в поле "Туннельный сервер" на вкладке "Туннель".
