# Провайдер Горизонт-ВС

> Описываемый функционал доступен начиная с версии брокера 4.0

Данный тип сервис-провайдера предоставляет возможность публикации сервисов виртуальных рабочих столов с использованием системы виртуализации Горизонт-ВС.

## Создание сервис-провайдера <a href="#provider" id="provider"></a>

Для создания сервис-провайдера зайдите в раздел "Сервисы", нажмите "Новый" и выберите тип провайдера "Горизонт-ВС".

### Основные настройки <a href="#main" id="main"></a>

**Имя (Name)** - наименование создаваемого провайдера для отображения в системе.

**Хост (Host)** - IP-адрес или FQDN сервера Горизонт-ВС.

**Порт (Port)** - порт подключения.

**Использовать SSL (Use SSL)** - если включено, будет использоваться ssl подключение к серверу.

**Имя пользователя (Username)** - имя пользователя с административными привилегиями в системе Горизонт-ВС.

**Пароль (Password)** - пароль пользователя.

### Расширенные настройки <a href="#advanced" id="advanced"></a>

**Одновременное создание (Creation Concurrency)** - количество одновременных задач создания рабочих столов.

**Одновременное удаление (Removal Concurrency)** - количество одновременных задач удаления рабочих столов.

**Таймаут (Timeout)** - тайм-аут подключения к Горизонт-ВС (в секундах).

Проверить подключение к провайдеру с заданными настройками можно с помощью кнопки "Проверить".

Для завершения настройки провайдера нажмите `Сохранить`.

## Создание сервисов <a href="#services" id="services"></a>

После завершения настройки провайдера откройте его параметры с помощью двойного щелчка, перейдите на вкладку "Сервисы", нажмите "Новый" и выберите тип создаваемого сервиса:

* Действующие образы Горизонт-ВС (Gorizont-VS Live Images) - для публикации виртуальных рабочих столов на основе "золотого" образа.

### Основные настройки <a href="#service-main" id="service-main"></a>

**Имя (Name)** - наименование создаваемого сервиса.

**Хранилище (Datastore)** - хранилище виртуальных машин сервиса.

### Машина <a href="#service-machine" id="service-machine"></a>

**Базовый шаблон (Base Template)** - "золотой" образ ВМ, используемый брокером для развертывания виртуальных рабочих столов.

**Имена машин (Machine Names)** - базовое имя машины, используемое для создаваемых виртуальных рабочих столов (например, CloneVM- )

**Длина имени (Name Length)** - размер числового суффикса, добавляемого к базовому имени машины (например, Длина имени = 2 -> CloneVM-00, CloneVM-01 и т.д).

Для завершения настройки сервиса нажмите `Сохранить`.
