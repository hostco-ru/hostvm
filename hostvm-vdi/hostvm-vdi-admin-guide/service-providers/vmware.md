# Провайдер VMware

Данный тип сервис-провайдера предоставляет возможность публикации сервисов виртуальных рабочих столов с использованием платформы виртуализации VMware.

## Создание сервис-провайдера <a href="#provider" id="provider"></a>

Для создания сервис-провайдера VMware перейдите в раздел «Сервисы», нажмите «Новый» и выберите тип провайдера «VMware».

### Основные настройки <a href="#main" id="main"></a>

**Имя (Name)** - наименование создаваемого провайдера для отображения в системе.

**Хост (Host)** - IP-адрес или FQDN сервера VMware vCenter.

**Порт (Port)** - порт подключения к серверу VMware vCenter (по умолчанию 443).

**Имя пользователя (Username)** - имя пользователя с административными привилегиями в vCenter.

**Пароль (Password)** - пароль пользователя.

### Расширенные настройки <a href="#advanced" id="advanced"></a>

**Одновременное создание (Creation concurrency)** - количество одновременных задач создания рабочих столов.

**Одновременное удаление (Removal concurrency)** - количество одновременных задач удаления рабочих столов.

**Диапазон MAC-адресов (MACs range)** - диапазон MAC-адресов для присвоения создаваемым виртуальным рабочим столам. Должен находиться в пределах 00:50:56:10:00:00-00:50:56:3F:FF:FF.

## Создание сервисов <a href="#services" id="services"></a>

После завершения настройки провайдера откройте его параметры с помощью двойного щелчка, перейдите на вкладку "Сервисы", нажмите "Новый" и выберите тип создаваемого сервиса:

* Связанные клоны VMware (VMware linked clones) - для публикации виртуальных рабочих столов на основе "золотого" образа.
* Фиксированные машины VMware (VMware fixed machines) - для подключения пользователей к существующим виртуальным машинам платформы виртуализации. _Данный тип сервиса доступен начиная с версии брокера 4.0._

### Связанные клоны <a href="#linked-clones" id="linked-clones"></a>

#### Основные настройки <a href="#linked-main" id="linked-main"></a>

**Имя (Name)** - наименование создаваемого сервиса для отображения в системе.

**Датацентр (Datacenter)** - датацентр в VMware vSphere для размещения сервиса.

**Пул ресурсов для публикации (Publication Resource Pool)** - пул ресурсов для размещения публикаций и виртуальных рабочих столов.

**Хранилище для публикации (Publication Datastore)** - хранилище данных для размещения публикации сервиса.

**Оставлять при ошибке (Keep on error)** - если включено, при обнаружении ошибок доступа к машине она не будет переведена в статус "Ошибка".

**Удалять найденные дубликаты (Remove found duplicates)** - если включено, при обнаружении дубликатов клонов этого сервиса они будут удаляться.

**Сначала попробовать SOFT Shutdown (Try SOFT Shutdown first)** - если включено, брокер попытается программно выключить машину. Задерживает отключение питания зависших машин примерно на 2 минуты.

#### Машина <a href="#linked-machine" id="linked-machine"></a>

**Пул ресурсов (Resource Pool)** - пул ресурсов, содержащий базовую машину.

**Базовая машина (Base Machine)** - "золотой" образ ВМ, используемый брокером для развертывания виртуальных рабочих столов.

**Память (Мб) (Memory (Mb))** - память, выдаваемая виртуальным рабочим столам.

**Сети (Network)** - сеть, подключаемая к виртуальным рабочим столам.

**Папка для клонов (Clones Folder)** - папка, где будут размещаться создаваемые виртуальные рабочие столы.

**Хранилище ВМ (VMs Datastore)** - хранилище для размещения виртуальных рабочих столов.

**Имена машин (Machine Names)** - базовое имя машины, используемое для создаваемых виртуальных рабочих столов (например, CloneVM- ).

**Длина имени (Name Length)** - размер числового суффикса, добавляемого к базовому имени машины (например, Длина имени = 2 -> CloneVM-00, CloneVM-01 и т.д).

#### Расширенные настройки <a href="#linked-advanced" id="linked-advanced"></a>

**Зарезервированное место (Reserved Space)** - минимальный порог свободного места в хранилище, для возможности разворачивания клонов (в ГБ).

### Фиксированные машины <a href="#fixed-machines" id="fixed-machines"></a>

> Данный тип сервиса доступен начиная с версии брокера 4.0.

#### Основные настройки <a href="#fixed-main" id="fixed-main"></a>

**Имя (Name)** - наименование создаваемого сервиса для отображения в системе.

**Токен сервиса (Service token)** - токен, используемый агентами для связи с сервисом (задается в виде произвольной последовательности букв и цифр). Если задано, брокер будет отслеживать "вход" и "выход" пользователя в сеанс ОС машины, и при выходе из сеанса автоматически освобождать машину, делая ее доступной для подключения другого пользователя. Если поле оставить пустым, машина будет оставаться постоянно закрепленной за пользователем (до ручного сброса администратором системы).

> Если поле `Токен сервиса` заполнено, на машины, заданные в качестве используемых сервисом, необходимо установить соответствующий агент VDI типа `Unmanaged`, и при его настройке задать такое же значение поля `Токен сервиса`, как и в настройках базового сервиса.

#### Машина <a href="#fixed-machine" id="fixed-machine"></a>

**Датацентр (Datacenter)** - датацентр в vSphere, в котором находятся машины.

**Пул ресурсов (Resource Pool)** - пул ресурсов в vSphere, в котором находятся машины.

**Машины (Machines)** - виртуальные машины выбранного пула ресурсов, предоставляемые пользователям данного сервиса. Отметьте нужные машины в списке.

#### Расширенные настройки <a href="#fixed-advanced" id="fixed-advanced"></a>

**Рандомизировать назначение машины (Randomize machine assignation)** - если включено, брокер будет назначать машины случайным образом вместо линейного.

**Оставлять при ошибке (Keep on error)** - если включено, при обнаружении ошибок доступа к машине она не будет переведена в статус "Ошибка".

**Использовать снапшоты (Use snapshots)** - если включено, брокер попытается создать снапшот (если еще не создан) перед доступом к машине и восстановить ее состояние после использования.
