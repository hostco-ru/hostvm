# Нотификаторы

> Описываемый функционал доступен начиная с версии брокера 4.0

Раздел "Инструменты / Нотификаторы" панели управления позволяет настроить автоматическую отправку уведомлений о событиях, фиксируемых в журналах брокера (уровень от Warning до Critical) через внешние системы.

## Создание нотификатора <a href="#create-notifier" id="create-notifier"></a>

Для создания нотификатора перейдите в раздел "Панель управления" > "Инструменты" > "Нотификаторы", нажмите "Новый", в выпадающем списке выберите тип нотификатора.

Доступные типы:

- уведомления по электронной почте;
- уведомления в Telegram.

### Уведомления по электронной почте <a href="#email-notifier" id="email-notifier"></a>

#### Основные настройки <a href="#email-main" id="email-main"></a>

**Имя** - имя создаваемого элемента для отображения в системе.

**Уровень** - уровень событий, по которым будут отправляться уведомелния. Доступные варианты: warning, error, critical.

**Включено** - если активно, нотификатор будет использоваться для отправки уведомлений. Чтобы приостановить отправку - деактивируйте эту настройку.

#### SMTP сервер <a href="#email-smtp" id="email-smtp"></a>

**SMTP сервер** - ip-адрес или имя сервера SMTP.

**Безопасность** - используемый криптографический протокол. Доступные варианты: tls, ssl, none.

**Имя пользователя** - пользователь для доступа к smtp серверу с разрешениями на отправку сообщений.

**Пароль** - пароль пользователя.

#### Конфигурация <a href="#email-config" id="email-config"></a>

**Отправитель** - адрес электронной почты отправителя (для поля From).

**Получатель** - адрес электронной почты получателя (для поля To).

**Включить HTML** - включить поддержку HTML кода в тексте сообщений.

### Уведомления в Telegram <a href="#tg-notifier" id="tg-notifier"></a>

#### Основные настройки <a href="#tg-main" id="tg-main"></a>

**Имя** - имя создаваемого элемента для отображения в системе.

**Уровень** - уровень событий, по которым будут отправляться уведомелния. Доступные варианты: warning, error, critical.

**Включено** - если активно, нотификатор будет использоваться для отправки уведомлений. Чтобы приостановить отправку - деактивируйте эту настройку.

#### Настройки Telegram <a href="#tg-config" id="tg-config"></a>

**Токен доступа** - токен доступа для Telegram-бота.

**Секрет** - секретный ключ для проверки запросов на подписку (команды /join или /subscribe)

**Задержка проверки** - интервал между проверками (в секундах).
