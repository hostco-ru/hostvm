# Группы серверов

> Описываемый функционал доступен начиная с версии брокера 4.0

Раздел "Сервисы / Серверы" панели управления позволяет добавлять группы серверов для последующего использования сервис-провайдерами, такими как RDS, RDS / Linux terminal и Провайдер машин со статическим IP.

## Создание группы <a href="#create-group" id="create-group"></a>

Для создания группы  перейдите в раздел "Сервисы" > "Серверы", нажмите "Новый", в выпадающем списке выберите тип группы.

Доступные типы групп серверов:

- Неуправляемый / RDS: для использования с провайдерами RDS и RDS / Linux terminal;
- Неуправляемый / IP: для использования с провайдером машин со статическим IP.

В открывшемся окне в поле "Имя" задайте имя группы для отображения в системе, нажмите "Сохранить".

## Добавление серверов в группу <a href="#add-server" id="add-server"></a>

После создания группы откройте ее с помощью двойного клика, либо через контекстное меню ПКМ > “Подробно”.

Для добавления сервера нажмите "Новый", в открывшемся окне задайте его параметры:

* **Имя** - имя сервера. Должно быть разрешимо брокером.
* **IP** - ip-адрес сервера. Используется, если имя не разрешается брокером или не указано.

Нажмите "Сохранить". Повторите процедуру для добавления всех требуемых серверов в группу.

После завершения настройки группы серверов, вы можете указать ее в настройках провайдера RDS, RDS / Linux terminal или провайдера машин со статическим IP (сервис Статический множественный IP-адрес) в поле "Группа серверов".

### Режим обслуживания <a href="#maintenance-mode" id="maintenance-mode"></a>

При временной недоступности одного или нескольких серверов, например для проведения запланированных работ, вы можете исключить их использование с помощью перевода в режим обслуживания.

Для этого отметьте нужный сервер в группе и нажмите кнопку "Войти в режим обслуживания".

После восстановления доступа выберите сервер и нажмите кнопку "Выйти из режима обслуживания".
