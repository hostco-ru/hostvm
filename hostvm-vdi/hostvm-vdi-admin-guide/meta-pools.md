# Настройка мета-пулов сервисов

Создание мета-пула позволяет получить доступ к виртуальным рабочим столам или приложениям, созданным из различных пулов сервисов и объединяя их. Эти пулы будут работать вместе, предоставляя различные услуги полностью прозрачно для пользователей.

## Создание мета-пула <a href="#create" id="create"></a>

Для создания мета-пула перейдите в раздел **Пулы -> Мета-пулы** и нажмите "Новый".

### Основные настройки <a href="#main" id="main"></a>

<figure><img src="https://raw.githubusercontent.com/hostco-ru/hostvm/master/.gitbook/assets/meta-pools2.png" alt=""><figcaption></figcaption></figure>

**Имя** (Name): имя мета-пула (это имя будет показано пользователю для доступа к его сервису: виртуальному рабочему столу или приложению)

**Короткое имя** (Short name): если указано, это будет название службы, которая будет показана пользователю. При наведении на него появится содержимое поля «Имя».

**Политика** (Policy):  политика балансировки нагрузки, применяемая при назначении сервисов пулов, являющихся частью мета-пула.

* **Evenly distributed**: сервисы будут распределяться в равной степени по всем сервис-пулам, составляющим мета-пул.
* **Priority**: сервисы будут распределяться в порядке приоритета сервис-пула (определяется полем «Приоритет», чем меньше значение этого поля, тем больший приоритет будет иметь пул). В первую очередь будут расходоваться сервисы пула с наивысшим приоритетом. При достижении максимального количества сервисов, начнут использоваться сервисы следующего по приоритету пула и т.д.
* **Greater % available**: будут использоваться сервисы пула, имеющего самый высокий процент свободных ресурсов на момент подключения.

_Изменения в версии 4.0:_

Добавлен параметр:

* `Политика высокой доступности (HA Policy)` - если политика активна, то при недоступности сервис-пула, входящего в мета-пул, сервисы пользователей будут автоматически запущены в следующем пуле, согласно заданной политике балансировки нагрузки.

### Экран/Дисплей <a href="#display" id="display"></a>

<figure><img src="https://raw.githubusercontent.com/hostco-ru/hostvm/master/.gitbook/assets/meta-pools3
.png" alt=""><figcaption></figcaption></figure>

**Привязанный образ** (Associated Image): изображение, связанное с мета-пулом.

**Группа пулов** (Pool group): предоставляет возможность группировать различные мета-пулы в группы пулов. Группу необходимо предварительно создать в разделе **Пулы** -> **Группы**.

**Видимый** (Visible): если этот параметр отключен, мета-пул не будет отображаться как доступный для пользователей на странице сервисов брокера HOSTVM VDI.

**Доступ к календарю запрещен** (Calendar Access denied text): текст, который будет отображаться, когда доступ к мета-пулу запрещен приложением календаря доступа.

**Выбор транспорта** (Transport Selection): в этом свойстве указывается, как транспорты будут доступны мета-пулу:

* **Automatic selection**:  доступный транспорт с наименьшим приоритетом, назначенным пулу сервисов, будет доступен в мета-пуле. Выбор транспорта пользователем запрещен.
* **Use only common transports**:  существующие транспорты, которые являются общими для всего пула сервисов, будут доступны в мета-пуле.
* **Group Transports by label**:  Те транспорты, которые имеют разные и сгруппированные «метки», будут доступны в мета-пуле (это поле есть внутри каждого транспорта на вкладке «Расширенный»)

## Добавление сервис-пулов <a href="#add-service-to-meta" id="add-service-to-meta"></a>

После завершения настройки мета-пула откройте его параметры с помощью двойного щелчка, перейдите на вкладку "Сервис-пулы", нажмите "Новый" и задайте параметры добавляемого сервис-пула:

<figure><img src="https://raw.githubusercontent.com/hostco-ru/hostvm/master/.gitbook/assets/meta-pools4.png" alt=""><figcaption></figcaption></figure>

Вы можете добавить столько пулов сервисов, сколько вам нужно, объединяя сервисы, размещенные на разных платформах виртуализации (VMware, KVM, Azure и т. д.), серверы приложений и статические устройства.

<figure><img src="https://raw.githubusercontent.com/hostco-ru/hostvm/master/.gitbook/assets/meta-pools5.png" alt=""><figcaption></figcaption></figure>

Как и в пуле сервисов, здесь вы также будете иметь следующую информацию и разделы:

* **Назначенные сервисы**: отображает сервисы, назначенные пользователям, позволяя выполнять ручное удаление и переназначение другому пользователю.
* **Группы**: указывает, какие группы пользователей будут иметь доступ к мета-пулу.
* **Доступ к календарям**: позволяет применить ранее созданный календарь доступа.
* **Журналы**: отображаются все проблемы, возникшие в мета-пуле.
