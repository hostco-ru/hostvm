# Custom

`Cookies consent enabled` - отображение уведомления об использовании файлов cookie на стартовой странице портала пользователя.

`Cookies consent text` - текст уведомления. Если пусто, будет использован текст по умолчанию.

`CSS` - код CSS, дополнительно применяемый к страницам портала пользователя для изменения стиля по умолчанию.

`Logo name` - текст, отображаемый рядом с логотипом на верхней панели навигации страниц портала пользователя.

`Min.Services to show filter` - минимальное количество сервисов, отображаемых пользователю на странице портала, для появления опции поиска/фильтра.

`Show Filter on Top` - позволяет изменить расположение элемента поиска/фильтра сервисов на странице.

`Site copyright info` - текст, отображаемый в правом нижнем углу стартовой страницы портала пользователя.

`Site copyright link` - URL-адрес ссылки для текста параметра Site copyright info.

`Site information` - текст или HTML-код, для отображения под формой ввода учетных данных.

`Site name` - текст, отображаемый над формой ввода учетных данных.

**Изменения в версии 4.0**

Добавлены параметры:

`Cookies consent leave url` - URL для покидания страницы при отказе от использования файлов cookie.

`Cookies consent more info url` - URL для получения дополнительной информации о файлах cookie.
