# Security

`allowRootWebAccess` — разрешить суперпользователю доступ через web-интерфейс брокера.

Изменение этого параметра не влияет на доступ суперпользователя root к консоли операционной системы.

По умолчанию: включено.

`Behind a proxy` — указывает, что брокер находится "за" прокси-сервером (например при развертывании конфигурации высокой доступности с использованием балансировщика нагрузки).

По умолчанию: выключено.

`Block ip on login failure` — в случае блокировки пользователя после нескольких неудачных попыток входа в систему также блокировать его IP-адрес.

По умолчанию: выключено.

`loginBlockTime` — время блокировки пользователя (в секундах), совершившего слишком много неудачных попыток входа в систему (количество попыток задается параметром maxLoginTries).

По умолчанию: 300 (5 минут).

`Master Key` — ключ для регистрации агента HOSTVM VDI (применимо к версиям до 2.2 включительно, начиная с 3.0 не используется).

`MaxLoginTries` — максимальное количество попыток входа в систему до временной блокировки учетной записи пользователя.

`RootPass` — пароль суперпользователя для доступа к web-порталу брокера.

`SuperUser` — имя суперпользователя для доступа к web-порталу брокера.

По умолчанию: root.

`Session timeout for Admin` — максимальная продолжительность бездействия для администратора (в секундах), по истечении которого будет выполнен выход из системы.

`Session timeout for User` — максимальная продолжительность бездействия для пользователя (в секундах), по истечении которого будет выполнен выход из системы.

`Trusted Hosts` — сети или хосты, которые брокер будет считать доверенными.  Эти узлы могут выполнять "конфиденциальные" запросы к брокеру (например HOSTVM VDI Туннелер).

Допускается ввод подсетей, диапазона IP-адресов и IP-адресов.

По умолчанию: "\*" (разрешить все).

**Изменения в версии 4.0**

Добавлены параметры:

`Allowed IP forwarders` - IP-адреса или сети, для которых разрешена отправка x-forwarder-for заголовков (например балансировщики нагрузки).

По умолчанию: "\*" (разрешить всем).
