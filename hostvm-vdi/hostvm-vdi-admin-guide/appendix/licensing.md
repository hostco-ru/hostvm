# Учёт количества лицензий

Для контроля оставшихся лицензий загрузите скрипт `LicenseController.py` из директории `HOSTVM VDI/Misc` в [Личном Кабинете](https://lk.pvhostvm.ru/) и поместите его в любую директорию на брокере HOSTVM VDI.

После загрузки запустите скрипт:

```
python3 LicenseController.py
```

## Выбор метрики и количества лицензий <a href="#script-metrics" id="script-metrics"></a>

```
Метрики лицензирования:
1. Именованные пользователи;
2. Одновременные (конкурентные) пользователи.

Выберите используемую метрику лицензирования: 1
```

После выбора метрики лицензирования введите количество приобретённых лицензий:

```
Введите количество приобретённых лицензий: 100
```

В результате работы скрипта в консоль будет выведена информация о превышении или не превышении лицензий и остатке лицензий:

```
Осталось лицензий: 1
```

### Период расчёта для метрики «Одновременные пользователи» <a href="#concurrent-users-period" id="concurrent-users-period"></a>

При выборе метрики **«Одновременные пользователи»** появится выбор периода расчёта:

```
Выберите период расчета:
1. Конкретная дата (ГГГГ-ММ-ДД)
2. За последние 30 дней
3. Произвольный интервал дат

Выберите вариант периода [1-3] (по умолчанию 2):
```

* **Вариант 1 (Конкретная дата):** скрипт запросит ввод даты в формате `ГГГГ-ММ-ДД`.
* **Вариант 2 (За последние 30 дней):** выведет информацию автоматически за последние 30 дней (выбрано по умолчанию).
* **Вариант 3 (Произвольный интервал дат):** запросит дату начала и окончания:

```
Введите дату начала (ГГГГ-ММ-ДД): 2026-09-01
Введите дату окончания (ГГГГ-ММ-ДД): 2026-09-15
```

## Устранение возможных ошибок <a href="#troubleshooting" id="troubleshooting"></a>

В случае возникновения ошибки:

```
Traceback (most recent call last):
  File "/root/LicenceController.py", line 17, in <module>
    import mysql.connector as ms
ModuleNotFoundError: No module named 'mysql'
```

Установите соответствующий модуль:

```
pip3 install mysql-connector-python
```
